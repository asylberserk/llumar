# Luxfil: перенос сайта сюда и визуальная доработка

Сайт по детейлингу живёт в проекте [Luxfil Automotive Excellence](/projects/38cbe31a-8cad-4c9e-b797-8d782d019456). Этот проект пока пустой шаблон, поэтому первым шагом переносим сайт сюда, дальше улучшаем дизайн.

## Что уже есть в Luxfil

- Страницы: главная, услуги (+детальные), плёнки, продукты (+детальные), проекты (+детальные), LLumar, о компании, контакты.
- Компоненты сайта: навигация, футер, карточки, формы заявки, модалка консультации, мобильный CTA, анимации Reveal.
- Дизайн-система: тёмный графит + шампанское, Manrope/Inter, острые радиусы (4px).
- 8 изображений в src/assets.

## Шаг 1. Перенос

Копируем полную кодовую базу Luxfil в текущий проект: маршруты, компоненты, данные, ассеты, стили, зависимости из package.json. Заглушка на `/` заменяется главной страницей Luxfil. Проверяем сборку и все маршруты в превью.

Оригинальный проект остаётся нетронутым.

## Шаг 2. Визуальная доработка

Сохраняем фирменный тон (тёмный графит + шампанское) и усиливаем «премиальность»:

- Главная: более кинематографичный герой — крупная типографика, глубина за счёт слоёв и мягкого свечения, сдержанная анимация появления при скролле.
- Единая сетка и ритм отступов по всем страницам, чтобы разделы не выглядели как набор блоков.
- Карточки услуг/продуктов/проектов: аккуратные состояния наведения, единый стиль изображений (одинаковые пропорции, лёгкое затемнение, подпись поверх).
- Типографика: чёткая иерархия заголовков, увеличенный трекинг у надзаголовков, ограничение ширины текста для читаемости.
- Кнопки и формы: одна выразительная основная кнопка, аккуратные фокус-состояния, состояния ошибки/успеха в форме заявки.
- Мобильная версия: проверка каждого экрана, липкий CTA, крупные зоны нажатия.
- SEO: у каждой страницы свой title/description/og.

Всё через токены в `src/styles.css` — без хардкода цветов в компонентах.

если ты уже установил себе то что я просил установить с github то применишь свою надсмотренность оттуда

## Технические детали

- Стек здесь тот же (TanStack Start + Tailwind v4), поэтому перенос идёт файл в файл; `routeTree.gen.ts` регенерируется автоматически.
- Шрифты Manrope/Inter подключаются через `<link>` в `__root.tsx`, не через `@import` в CSS.
- Зависимости Luxfil (shadcn ui, анимации) доустанавливаются здесь.
