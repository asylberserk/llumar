# Hero: scroll-Linked появление лозунга

## Что делаем
Добавить на главную элегантную скролл-анимацию в hero-секции: при первом появлении страницы виден только логотип LUXFIL, при скролле поочерёдно проявляются локация, лозунг, описание, кнопки и индикатор "Листайте".

## Текущее состояние
В `src/routes/index.tsx` hero выводит сразу все элементы: eyebrow, логотип, заголовок, описание, CTA и стрелку прокрутки. Анимационная система уже есть (`Reveal`, CSS-утилиты `reveal-hidden`/`reveal-shown`), но они работают по IntersectionObserver и не подходят для внутриhero-прокрутки.

## Решение

### 1. Scroll-driven reveal
- Добавить в hero локальный хук/компонент, который слушает прокрутку страницы через `requestAnimationFrame` и вычисляет прогресс от 0 до 1 внутри первых ~200 px скролла.
- Элементы обернуть в группы с inline-стилями `--hero-reveal: 0..1`, управляющими `opacity` и `transform: translateY(20-28px)`.
- Появление — поэтапное (stagger), каждый следующий блок начинает проявляться, когда предыдущий достиг ~60-70%:
  1. eyebrow "Бишкек · Кыргызстан"
  2. заголовок, строка 1: "Технологии защиты."
  3. заголовок, строка 2: "Без компромиссов." (с цветом primary)
  4. описание
  5. CTA-кнопки
  6. "Листайте" + стрелка
- Логотип LUXFIL остаётся видимым с самого начала, без анимации.

### 2. Визуальный стиль
- Использовать существующие токены: `var(--champagne)`, `var(--primary)`, `var(--foreground)`, `var(--muted-foreground)`.
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)` — уже используется в `reveal-shown`.
- Длительность перехода: 700-900 мс на элемент, но привязана к скроллу, так что пользователь сам контролирует темп.
- Без новых зависимостей и без неона/градиентов, не свойственных текущей системе.

### 3. Доступность и fallback
- `prefers-reduced-motion: reduce` — отключить скролл-привязку, показать весь контент сразу (или мгновенное появление без transform).
- Touch-устройства: скролл работает как обычно, анимация остаётся, потому что она привязана к прокрутке, а не к hover.
- Не анимируем `width`/`height`, только `transform` и `opacity`.

### 4. Файлы
- `src/routes/index.tsx` — обернуть hero-контент в scroll-reveal группы.
- `src/styles.css` — добавить утилиты `.hero-reveal-*` с CSS-переменными.
- Возможно, новый хук `src/hooks/useHeroScroll.ts` если логика удобнее вынести.

### 5. Проверка
- `bun run tsgo --noEmit` — типизация.
- `/tmp/observability/build-errors.log` — сборка.
- Playwright: открыть `/`, сделать скриншот до скролла (виден только логотип), проскроллить на 150 px и убедиться, что появились лозунг и описание; проверить `prefers-reduced-motion`.
